# Python Base Guide

This file is the canonical home for Python engineering guidance that applies across supported Python versions.

Keep this guide version-neutral. Add guidance here only when it is expected to hold for all supported Python versions used by projects.

Version-specific files in `versions/` must contain only meaningful differences from this base guide.

## Purpose

- Capture durable Python engineering preferences.
- Reduce repeated decisions across Python projects.
- Provide portable guidance that can be copied into standalone repositories.

## Future Content

Future Python guidance may cover:

- project layout
- dependency management
- typing expectations
- testing conventions
- packaging
- error handling
- command-line interfaces
- performance profiling
- documentation expectations

Do not add project-specific rules here.
