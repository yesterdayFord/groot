# Zig Base Guide

This file is the canonical home for Zig engineering guidance that applies across supported Zig versions.

This is a scaffold only. Do not treat it as an established Zig language standard yet.

## Purpose

- Reserve the canonical location for future Zig-wide engineering guidance.
- Make future Zig project guidance portable into standalone repositories.
- Keep language-wide rules separate from project-specific matching-engine rules.

## Future Content

Future Zig guidance may cover:

- project layout
- allocator policy
- error handling
- ownership and lifetime conventions
- testing style
- performance measurement
- build system conventions
- C interop expectations

Do not add project-specific rules here.
