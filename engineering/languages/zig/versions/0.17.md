# Zig 0.17 Delta

This file is reserved for Zig 0.17-specific guidance.

As of 2026-07-27, Zig 0.17.0 is not treated here as a released stable target. The official Zig download page lists 0.16.0 as the current release, and the 0.16.0 release notes describe the 0.17.0 cycle as upcoming.

Projects may target a pinned Zig 0.17 development compiler, but project guidance must record the exact `zig version` output and should not describe that target as "Zig 0.17.0" unless a release exists.

Do not duplicate the Zig base guide here. Add guidance only when a rule can be tied to verified Zig 0.17 compiler or standard-library behavior.

## Current Delta

No durable Zig 0.17-specific guidance has been established yet.

## Development Compiler Policy

When a project uses a Zig 0.17 development build, its project-local guidance should record:

- exact `zig version` output
- source, toolchain manager, or install path when relevant
- date the compiler target was chosen
- any observed compiler or standard-library behavior that differs from released Zig guidance

Do not promote local API preferences, deterministic-systems rules, or general Zig practices into this version delta.
