# Groot

Groot is a personal knowledge system for organizing durable context across work, life, engineering projects, decisions, and reusable standards.

Start with [groot.md](groot.md) for the system vision and current architecture.

## Current Scope

The project is in its architecture phase.

Current implemented structure:

- `groot.md` - system vision, principles, and high-level architecture
- `engineering/languages/` - canonical language-wide engineering guidance architecture

## Repository Principles

- Groot owns long-lived guidance.
- Individual project repositories own implementation.
- Standalone projects must remain portable and must not depend on Groot.
- Durable project lessons should be processed back into Groot deliberately.
